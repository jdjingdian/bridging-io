## 为什么

当前 menuconfig 交互里，底部按钮（`[<Select>]`、`< Exit >`、`< Help >`）已经对选中态做了反色高亮，但菜单项本身的选中态仍与未选中态视觉接近。用户在键盘上下移动时不够直观，容易增加误选成本。

## 变更内容

- 为 menu 列表中的“当前选中项”增加反色渲染，形成与按钮区一致的高可见选中态。
- 统一菜单项与底部按钮的焦点反馈策略：当项处于焦点/选中状态时都使用明确的反色效果。
- 明确当终端不支持反色能力时的降级策略，避免可读性回退。
- 补充与选中态相关的验收与回归测试要求，覆盖键盘导航场景。

## 功能 (Capabilities)

### 新增功能
- `menuconfig-selection-contrast`: 规范 menuconfig 中菜单项选中态的反色渲染、降级行为与一致性要求。

### 修改功能
- 无

## 影响

- 受影响模块：menuconfig 菜单渲染层、焦点状态样式映射、终端能力探测/样式降级路径。
- 受影响体验：键盘导航时的视觉定位与误选风险。
- 受影响验证：需要补充选中态样式与终端兼容性的测试用例。
