## 新增需求

### 需求:macOS 控制台必须展示目标与会话状态
macOS SwiftUI 控制台必须提供目标列表和会话详情视图，并且必须展示目标类型、连接状态、最近活动时间、环境指纹摘要和能力摘要。

#### 场景:查看已连接目标的会话详情
- **当** 用户在控制台中选中一个已连接目标
- **那么** 系统必须显示该目标的当前会话状态、环境摘要和可用能力，而不是只显示一块空白终端区域

### 需求:命令交互必须以可折叠时间线展示
控制台必须以事件时间线或命令卡片的形式展示 AI 与目标的交互过程。每个命令事件必须至少包含请求时间、执行状态、摘要、stdout/stderr 的查看入口以及关联 artifact 标识。

#### 场景:命令产生大量输出
- **当** 某条命令产生超长输出
- **那么** 控制台必须默认展示摘要或折叠视图，并允许用户展开查看原始输出或跳转到 artifact 详情

### 需求:审批与敏感操作反馈必须可见
控制台必须展示待处理审批、审批结果以及与命令相关的敏感操作反馈。用户必须能够在控制台中区分“等待审批”、“已批准执行”和“被拒绝执行”等状态。

#### 场景:命令等待用户批准
- **当** 某条命令因策略要求进入审批流程
- **那么** 控制台必须显示清晰的审批状态和上下文，直到该请求被批准、拒绝或超时结束
